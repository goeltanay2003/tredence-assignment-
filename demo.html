🔄 Demo 3: Looping Workflow

Nodes can loop back to earlier nodes, enabling iterative processing until a condition is met.

START
→
INCREMENT
loop back ↻

Loop Logic: Until counter >= 5

Iteration 1: counter = 0 → 1 (1 < 5, continue)
Iteration 2: counter = 1 → 2 (2 < 5, continue)
Iteration 3: counter = 2 → 3 (3 < 5, continue)
Iteration 4: counter = 3 → 4 (4 < 5, continue)
Iteration 5: counter = 4 → 5 (5 >= 5, exit loop)

✨ Key Features of the Workflow Engine

📌 Sequential Processing

Nodes execute in order, passing data through a shared state. Perfect for pipelines.

🔀 Conditional Routing

Route execution based on state values. Supports: >, <, >=, <=, ==, !=

🔄 Looping

Loop back to earlier nodes with max iteration protection to prevent infinite loops.

💾 State Management

Shared WorkflowState flows through all nodes. Each node can read and modify it.

🛠️ Tool Registry

Register Python functions dynamically. Nodes call tools to perform work.

📊 Execution Logging

Track every node execution with timing, status, and state snapshots.
